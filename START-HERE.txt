CLONE CENTRAL - FIRST AUDIO EXPERIMENTS
======================================
This is an experimental Windows package, not yet a finished application.
It contains SOURCE CODE AND LAUNCHERS, not pretrained model weights or audio recordings.

1) Extract ZIP into a normal folder (for example Documents\CloneCentral).
2) Install Python 3.12 for Windows if not already installed; enable the Python launcher.
3) On a device authorized to run this software, double-click:
   - VOICE-EXPERIMENT.cmd for narration in a cloned reference voice.
   - MUSIC-EXPERIMENT.cmd to separate vocals from accompaniment.
4) The first run can download substantial third-party models and dependencies.
5) Audio goes to the outputs folder. Personal input files remain local.

If Windows or your employer's security policies block execution, do not bypass them.
Read RUN.md for full instructions, requirements and troubleshooting.

No Qwen inference, Demucs execution, audio fidelity or Surface CPU performance
is claimed to have passed until actual hardware test evidence exists.
