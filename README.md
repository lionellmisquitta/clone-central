# Clone Central

Local-first experiments in **voice cloning** and **music stem separation**. The first objective is to create real WAVs and measure performance before building an interface.

**Status:** experiment code under review; no inference or quality claim until a real run produces and validates audio.

Voice and music are equally important. Quality presets are `fast`, `balanced`, and `studio` (actual quality depends on model and hardware). No model weights, personal voice recordings, music recordings, or outputs are stored in this Git repository.

See the proposed experiment scripts in the `CHG-001/audio-first-spikes` branch and its pull request. Only use recordings you own or are authorized to process. On managed equipment, follow endpoint security policy.
